DETAILED DESCRIPTION (paste into the store listing):
──────────────────────────────────────────────────────────────────────────────
Connect your Google Keep notes to Claude Desktop — no API keys, no OAuth, no passwords stored anywhere.

HOW IT WORKS
• Keep a Google Keep tab open in Chrome
• Run the included bridge server (one double-click to start)
• Ask Claude anything about your notes

EXAMPLE QUESTIONS YOU CAN ASK CLAUDE
• "What restaurants do I have saved in Keep?"
• "Summarise my project notes"
• "Do I have anything about my fence project?"
• "What's on my CCTV business plan?"

PRIVACY — YOUR DATA NEVER LEAVES YOUR COMPUTER
The extension reads your visible Keep notes from the browser tab (the same notes you can see on screen) and sends them only to a local server running on your own machine (localhost:8080). Nothing is sent to any external server. No account is created. No data is stored.

WHAT IT INSTALLS
• This Chrome extension (reads Keep notes from the open tab)
• A small Node.js bridge server you run locally
• A Claude Desktop MCP configuration that lets Claude call the server

REQUIREMENTS
• Chrome (or any Chromium-based browser)
• Node.js installed on your computer
• Claude Desktop app (free from claude.ai)
• Google Keep open in a Chrome tab

SETUP TAKES ABOUT 2 MINUTES
1. Install this extension
2. Run the installer from the GitHub repo (double-click install.bat)
3. Restart Claude Desktop
4. Open keep.google.com in Chrome
5. Ask Claude about your notes
