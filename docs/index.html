100% Private

Notes are read from your open Chrome tab and sent only to a local server on your own machine. Nothing goes to any external server.

⚡

Instant Setup

No API keys, no OAuth, no passwords. Install the extension, run the bridge server, and you're ready in under 2 minutes.

🔍

Native Search

Uses Keep's own search bar to find notes across your entire library — not just what's visible on screen.

🔄

Always Up to Date

A live cache updates automatically as you scroll through your notes, so Claude always sees the latest version.
